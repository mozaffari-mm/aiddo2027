# AIDDO 2027

Website for **AIDDO 2027 — AI for Database Schema Design and Optimization**, a workshop at IEEE ICDE 2027.

## Recommended repository

Create a GitHub organization, for example:

`AIDDO-Workshop`

Then create a public repository:

`aiddo-workshop.github.io`

Upload the contents of this folder to the repository root and use `main` as the default branch.

## GitHub Pages

This repository includes a GitHub Actions workflow at:

`.github/workflows/pages.yml`

After the first push:

1. Open repository **Settings**
2. Open **Pages**
3. Under **Build and deployment**, choose **GitHub Actions**
4. The included workflow will deploy the site

## Before public announcement

Update these items as soon as they are known:
- exact workshop date
- submission-system URL
- final paper formatting instructions
- dedicated workshop email
- invited-speaker photos/bios (optional)
- final program and accepted papers

## Content source

The initial website content follows the accepted AIDDO workshop proposal. The CFP scope has been intentionally broadened in response to the ICDE 2027 Workshop Chairs' suggestion to attract a wider audience while retaining database schema design and optimization as the workshop's core.
